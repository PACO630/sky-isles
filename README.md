# 雲海群島 Sky Isles

一款可以直接在瀏覽器玩的 3D 合作探索遊戲。和朋友一起在無盡的浮空群島之間跳躍、滑翔，收集星光碎片，點亮古老的祭壇。

- 手機和電腦都能玩，不用安裝（手機請橫向遊玩）
- 多人連線採 P2P（WebRTC + Trystero），**不需要架伺服器**，可以直接放在 GitHub Pages
- 世界是用種子程序生成的，可以無限延伸；相同的「世界代碼」就是同一個世界

## 玩法

| 動作 | 電腦 | 手機 |
|---|---|---|
| 移動 | WASD／方向鍵 | 左半邊螢幕拖曳 |
| 奔跑 | Shift | 搖桿推到底 |
| 跳躍 | 空白鍵 | 右下角圓形跳躍鈕 |
| 滑翔 | 空中再按住空白鍵 | 空中再按住跳躍鈕 |
| 互動 | E | 靠近祭壇時出現的互動鈕 |
| 表情／標記 | 1–4 | 右側笑臉按鈕 |
| 旅人日誌 | J | 左上角書本按鈕 |
| 轉視角 | 拖曳滑鼠，滾輪縮放 | 右半邊螢幕拖曳 |

- **星光碎片**：散落在各個島上，碰到就會撿起來
- **祭壇**：用 3 片碎片點亮，會升起一道很遠就看得到的光柱，也能聆聽祭壇的低語
- **上升氣流**：島嶼邊緣閃爍的白色光點，滑翔進去就會被往上推，可以飛到更高的島
- **祭壇之門**：在點亮的祭壇前互動，可以聆聽低語，並傳送到任何一座已點亮的祭壇（隊友點亮的也可以）
- **雲鯨**：背著小花園的巨大雲鯨在高空巡游。滑翔到牠的腹下，氣流會把你送上背部，牠會載著你旅行；背上還藏著一片碎片
- **夜晚流星**：晚上偶爾會有流星墜落在附近的島上，跟著指南針上的藍色星光找到它，可以得到 2 片碎片
- **指南針**：畫面上方顯示方位、祭壇光柱、出生島、隊友、標記和流星的方向與距離
- **表情與標記**：揮手、歡呼、愛心；「這裡！」會在你的位置升起一道光柱，隊友的指南針上也看得到
- **旅人日誌**：探索統計，以及收集到的 16 段祭壇低語
- 掉進雲海會回到上一個安全的地點
- 日夜循環跟現實時間同步（12 分鐘一天），大家看到的天空都一樣

## 多人連線

按右上角的「邀請朋友」複製連結，朋友打開同一個連結就會進入同一個世界。一個房間建議 2～8 人。
進度存在各自的瀏覽器裡；大家碰面時會自動合併「撿過的碎片」和「點亮的祭壇」。

## 開發

需要 Node.js 18 以上。

```bash
npm install
npm run dev
```

## 部署到 GitHub Pages

1. 在 GitHub 建一個新的 repository，把這個資料夾推上去（分支名稱用 `main`）
2. 到 repository 的 **Settings → Pages**，Source 選 **GitHub Actions**
3. 之後每次推到 `main`，`.github/workflows/deploy.yml` 都會自動建置並發布

## 程式結構

| 檔案 | 內容 |
|---|---|
| `src/main.js` | 遊戲主迴圈、介面、多人同步邏輯 |
| `src/world.js` | 島嶼程序生成、分區塊載入、碰撞查詢 |
| `src/whales.js` | 雲鯨（依時間決定位置，所有玩家看到的都一樣） |
| `src/events.js` | 夜晚流星 |
| `src/geo.js` | 低多邊形幾何合併工具 |
| `src/player.js` | 角色模型、移動／跳躍／滑翔物理 |
| `src/sky.js` | 天空、日夜循環、雲海、星星、螢火 |
| `src/input.js` | 鍵盤滑鼠和觸控搖桿 |
| `src/net.js` | P2P 多人連線 |
| `src/save.js` | 本機存檔 |
| `src/audio.js` | 合成音效 |
